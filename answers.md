What is a repository?  A repository is basically a folder where all your project files are stored. It also keeps a history of everything you've changed, so you can look back at older versions if you need to

What is a branch, and why do we use one instead of changing the main version directly? A branch is like a separate copy of the project where you can make changes without messing up the main version. 
We use them so if you make a mistake, it doesn't break the real project. Once you're happy with your changes, you can merge it back.

What is a commit? What makes a good commit message? A commit is when you save your changes to the project. A good commit message is short and explains what you did. Like "fixed the login button" instead of just "changed stuff."

What is a pull request, and what happens to it after you open one?  A pull request is when you ask to put your changes into the main project. 
After you open one, other people can look at your work, leave comments, and either approve it or say what needs fixing. If it's approved, it gets merged.

Why does someone else review your work before it is merged? So they can check for mistakes. Sometimes you miss things, so having someone else look at it helps catch bugs or problems before it goes live. 
It also helps everyone learn from each other.

What is Markdown? Give two examples of formatting you can do with it. Markdown is a way to format text using simple symbols. It's used for README files and things like that on GitHub. **bold** makes text bold - item makes a bullet point
